# ✦ AI Studio

Локальный десктопный ИИ-ассистент для Windows с современным интерфейсом, голосовым управлением, озвучкой ответов и системой плагинов. Работает на базе **Ollama**.

## ✨ Основные возможности

* **Локальные нейросети (Ollama):** Полная приватность и работа без облачных лимитов.
* **Голосовой ввод и отклик по кодовому слову:** Активация по слову-триггеру (по умолчанию — *«чупик»*) с мягким звуковым сигналом и автоматической отправкой запроса.
* **Озвучка ответов:** Естественный синтез речи (`edge-tts`) с возможностью мгновенно прервать фразу кнопкой `🔇`.
* **Полный доступ к файлам ПК:** Ассистент умеет искать, читать, создавать и редактировать файлы в любых папках на компьютере.
* **Работа с документами и медиа:** Поддержка создания и чтения **Word (`.docx`)** и **Excel (`.xlsx`)**, чтение **PDF**, анализ изображений (включая вставку скриншотов через `Ctrl+V`) и видеофрагментов.
* **Система скиллов и плагинов:** Возможность подключать собственные Python-скрипты в папку `ai_assistant_data/plugins`, а также встроенный поиск в интернете и терминал.
* **Долгосрочная память и темы:** Сохранение пользовательских правил и фактов между чатами, 5 встроенных цветовых тем оформления.

## 🚀 Установка и запуск (для пользователей Windows)

Для работы программы не нужно устанавливать Python, достаточно выполнить 3 шага:

### Шаг 1. Установите Ollama
1. Скачайте установщик с официального сайта [ollama.com](https://ollama.com) и установите программу.
2. Убедитесь, что Ollama запущена (в системном трее возле часов должен отображаться значок ламы).

### Шаг 2. Скачайте нейросеть
Откройте командную строку (`cmd`) или PowerShell и выполните команду для загрузки модели (она поддерживает вызов инструментов и скиллов):

```bash
ollama pull qwen3.5:4b
```

*(Вы также можете скачать любую другую модель в Ollama и выбрать её в верхнем меню программы).*

### Шаг 3. Запустите AI Studio
1. Перейдите в раздел **[Releases](../../releases)** этого репозитория и скачайте файл **`AI_Studio.exe`**.
2. Поместите `AI_Studio.exe` в отдельную пустую папку (например, `C:\AI_Studio`). При первом запуске программа создаст рядом папку `ai_assistant_data` для хранения чатов, настроек и плагинов.
3. Запустите `AI_Studio.exe`. Если Windows SmartScreen покажет предупреждение о неизвестном издателе, нажмите **«Подробнее» → «Выполнить в любом случае»**.

## 🛠 Запуск из исходного кода (для разработчиков)

Если вы хотите запускать или дорабатывать скрипт напрямую через Python:

1. Склонируйте репозиторий или скачайте архив с кодом:
   ```bash
   git clone https://github.com
   cd AI-Studio
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   python ai_studio.pyw
   ```

### Сборка собственного `.exe` файла
```bash
pyinstaller --noconfirm --onefile --windowed --collect-all customtkinter --collect-all edge_tts --collect-all docx --collect-all openpyxl --name "AI_Studio" ai_studio.pyw
```

## 📌 Примечания
* **Работа без интернета:** Генерация ответов, работа с файлами ПК, Word и Excel работают полностью автономно.
* **Работа с интернетом:** Для голосовой озвучки (`edge-tts`), распознавания речи (`Google Speech`) и веб-поиска требуется подключение к сети.
